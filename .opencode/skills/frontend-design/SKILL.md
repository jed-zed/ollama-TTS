# 前端设计技能

当用户请求前端设计帮助时，遵循以下指南：

## 设计流程

1. **需求理解** - 明确用户的设计目标和使用场景
2. **结构规划** - 设计组件层次和页面布局
3. **交互设计** - 规划用户操作流程和反馈机制
4. **视觉呈现** - 提供样式建议和设计规范

## 输出格式

### 组件设计
- 使用 Mermaid 图表展示组件结构和数据流
- 提供组件 props 接口定义
- 说明状态管理方案

### 页面布局
- 使用 ASCII 或 Mermaid 展示布局结构
- 标注响应式断点和适配策略
- 说明关键交互区域

### 样式建议
- 推荐配色方案和字体选择
- 提供间距和尺寸规范
- 考虑无障碍访问 (a11y)

## 设计原则

- **用户优先** - 以用户体验为核心
- **简洁清晰** - 避免过度设计
- **一致性** - 保持设计语言统一
- **可访问性** - 考虑各类用户需求
- **性能意识** - 设计时考虑加载和渲染性能

## 技术栈考虑

根据项目情况推荐合适的技术方案：
- React / Vue / Svelte 等框架选择
- CSS-in-JS / Tailwind / SCSS 等样式方案
- 状态管理和数据获取策略
- 组件库选择建议

## 示例输出

当设计一个组件时，提供：

```
## 组件名称：UserCard

### 功能描述
展示用户基本信息的卡片组件

### Props 接口
- user: { name, avatar, email }
- onClick?: () => void
- variant?: 'compact' | 'full'

### 组件结构
┌─────────────────────┐
│  [Avatar]  Name     │
│            Email    │
└─────────────────────┘
```
